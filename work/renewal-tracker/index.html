The brief

Subscriptions, insurance, MOT, TV Licence, passports — everything that renews, in one calm list, with a reminder before each one is due.

The approach

  1. 01

    A real desktop app

    Installable on Windows and Mac, with a Ctrl+K command palette and automatic background updates.

  2. 02

    A back end that does the work

    The API behind the app, plus a desktop reminder and a daily 8am email before anything is due.

  3. 03

    The website that sells it

    Designed and built in house, with the downloads for both platforms.
